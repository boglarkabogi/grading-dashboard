6. Beadandó

\(f = x^4 + 3 \in \mathbb{Z}_5[x]\)  
\(g = x^3 + x + 1 \in \mathbb{Z}_5[x]\)

\(x^3 + x + 1 = 0\)  
\(x^3 \equiv -x - 1 \equiv 4x + 1\)

\(f = x(4x + 1) + 3 = 4x^2 + x + 3 \quad \mathbb{Z}_5\)  
\(g = 4x + 1 + x + 1 = 5x + 2 \equiv 2 \quad \mathbb{Z}_5\)

a) \(f \cdot g \mod x^3 + x + 1\)

\(f \cdot g \equiv 2(4x^2 + x + 3) = 8x^2 + 2x + 6 \equiv 3x^2 + 2x + 1 \quad \mathbb{Z}_5\)

b) \(f \cdot g^2 + f^2 \cdot g \mod x^3 + x + 1\)

\(g^2 = 2^2 = 4\)

\(f^2 = (4x^2 + x + 3)^2 = 16x^4 + 4x^3 + 12x^2 + 4x^3 + x^2 + 3x + 12x^2 + 3x + 9\)  
\(= 16x^4 + 8x^3 + 25x^2 + 6x + 9\)  
\(= x^4 + 3x^3 + x + 4\)  
\(\equiv (4x^2 + x) + 3(4x + 1) + x + 4\)  
\(\equiv 4x^2 + 4x + 2\)

\(4f + 2g^2 = (x^2 + 4x + 2) + (3x^2 + 3x + 4) \equiv 4x^2 + 7x + 6 \equiv 4x^2 + 2x + 1\)

\(4f = 4(4x^2 + x + 3) = x^2 + 4x + 2\)

\(2f^2 = 2(4x^2 + 4x + 2) \equiv 3x^2 + 3x + 4\)

c) \(f^8 \mod x^3 + x + 1\)

\(f^4 \equiv 4x^2 + 4x + 2\)  
\(f^4 \equiv (4x^2 + 4x + 2)^2 \equiv x^4 + 2x^3 + 2x^2 + x + 4\)  
\(\equiv (4x^2 + x) + 2(4x + 1) + 2x^2 + x + 4\)  
\(\equiv x^2 + 1\)

\(f^8 \equiv (x^2 + 1)^2 \equiv x^4 + 2x^2 + 1\)  
\(\equiv 4x^2 + x + 2x^2 + 1\)  
\(\equiv x^2 + x + 1\)
