\( x^3 + x + 1 \equiv 0 \pmod{x^2 + x + 1} \Rightarrow x^3 \equiv -x - 1 \equiv 4x + 1 \pmod{x^2 + x + 1} \)

\( x^4 = x \cdot x^3 \equiv 4x^2 + x \pmod{x^2 + x + 1} \)

\( f = x^4 + 1 \equiv (4x^2 + x) + 1 = 4x^2 + x + 1 \pmod{x^2 + x + 1} \)

\( g = x^2 + 2x \equiv 4x + 1 + 2x = 6x + 1 \equiv x + 1 \pmod{x^2 + x + 1} \)

① \( f \cdot g \mod x^2 + x + 1 \)

\( (4x^2 + x + 1)(x + 1) = 4x^3 + 4x^2 + x^2 + x + x + 1 = 4x^3 + 5x^2 + 2x + 1 \)

\( 4x^3 + 5x^2 + 2x + 1 \equiv 4x^2 + 2x + 1 \)

\( f \cdot g^2 = (f \cdot g) \cdot (g + f) \)

\( g + f = 5x^2 + x + 1 + x + 1 = 5x^2 + 2x + 2 \)

\( (4x^2 + 2x + 1)(5x^2 + 2x + 2) = 16x^4 + 8x^3 + 8x^2 + 4x^2 + 4x + 4x^2 + 2x + 2 = 16x^4 + 16x^3 + 16x^2 + 6x + 2 \)
