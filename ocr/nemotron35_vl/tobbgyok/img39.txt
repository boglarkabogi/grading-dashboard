f = x^4 + 3  
g = x^3 + x + 1 ∈ Z_5[x]  
m = x^2 + x + 4  

x^4 + 3 ≡ 6x^2 + x + 3  
x^3 + x + 1 = m - 3 ≡ -3 ≡ 2  

1) f · g mod m  

f · g - 2f - 8x^3 + 2x + 6 ≡ 3x^2 + 2x + 1  

2) f · g^2 + f^2 · g mod m  

f · g^2 = 4f = 16x^2 + 4x + 12 ≡ x^2 + 4x + 2  

f^2 = (4x^2 + x + 3)^2 = x^4 + 3x^2 + x + 4 ≡ (4x^2 + x) + (2x + 3) + x + 4 ≡ 4x^2 + 4x + 2  

f^2 · g = 2f^2 = 8x^2 + 8x + 4 ≡ 3x^2 + 3x + 4  

(x^2 + 4x + 2) + (3x^2 + 3x - 4) = 4x^2 + 7x + 8x ≡ 4x^2 + 2x + 1  

3) f^8 mod m  

f^2 ≡ 4x^2 + 4x + 2  

f^4 ≡ (f^2)^2 = x^4 + 2x^3 + 2x^2 + x + 4 ≡ (4x^2 + x) + (3x + 2) + 2x^2 + x + 4 ≡ x^2 + 1  

f^8 = (x^2 + 1)^2 = x^4 + 2x^2 + 1 = 4x^2 + x + 2x^2 + 1 ≡ x^2 + x + 1
