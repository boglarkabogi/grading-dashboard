$f = x^4 + 2x^3 + x^2 + 4 \in \mathbb{Z}_5[x]$
$g = x^5 + x^4 + 2x^3 + 2x^2 + 2x + 1 \in \mathbb{Z}_5[x]$

$g = f \cdot (x+4) + (3x^3 + 3x^2 + 3x)$
$(x^5 + x^4 + 2x^3 + 2x^2 + 2x + 1) : (x^4 + 2x^3 + x^2 + 4) = x + 4$

$$\begin{array}{c}
-\quad x^5 \quad 2x^4 \quad x^3 \quad\quad\quad 4x \\
\hline
4x^4 + x^3 + 2x^2 + 3x + 1 \\
-\quad 4x^4 + 3x^3 + 4x^2 \quad\quad\quad + 1 \\
\hline
3x^3 + 3x^2 + 3x
\end{array}$$

$f = (3x^3 + 3x^2 + 3x)(2x + 2) + (4x^2 + 4x + 4)$

$(x^4 + 2x^3 + x^2 + 4) : (3x^3 + 3x^2 + 3x) = 2x + 2$
$$\begin{array}{r}
-\quad x^4 + x^3 + x^2 \\
\hline
x^3 + 4 \\
-\quad x^3 + x^2 + x \\
\hline
4x^2 + 4x + 4
\end{array}$$

$(3x^3 + 3x^2 + 3x) : (4x^2 + 4x + 4) = 2x$
$$\begin{array}{r}
3x^3 \quad 3x^2 \quad 3x \\
\hline
\boxed{0}
\end{array}$$

$3x^3 + 3x^2 + 3x = (4x^2 + 4x + 4)(2x) + 0$

$\Rightarrow \underline{x^2 + x + 4}$
