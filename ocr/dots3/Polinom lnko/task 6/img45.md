$$g - xf = (x^5 + x^4 + 2x^3 + 4x^2 + 4x + 3) - (x^5 + 2x^4 + 3x^3 + 2x^2 + x) =$$

$$r_1 = 4x^4 + 4x^3 + 2x^2 + 3x + 3$$

$$f: x^4$$
$$r_1: 4x^4$$

$$\frac{x^4}{4x^4} = \frac{1}{4} = 4^{-1} \equiv 4 \pmod 5 \quad \text{szerzete} = 4$$

$$4r_1 = x^4 + x^3 + 3x^2 + 2x + 2$$

$$f - 4r_1 = (x^4 + 2x^3 + 3x^2 + 2x + 1) - (x^4 + x^3 + 3x^2 + 2x + 2) =$$

$$r_2 = x^3 + 4$$

$$\frac{r_1}{r_2} = \frac{4x^4}{x^3} = 4x$$

$$r_2 \cdot 4x = 4x^4 + x$$

$$r_1 - (4x^4 + x) = 4x^4 + 4x^3 + 2x^2 + 3x + 3 - (4x^4 + x) = 4x^3 + 2x^2 + 2x + 3$$

$$\frac{r_2}{r_3} = \frac{x^3}{4x^3} = 4 \cdot \frac{1}{4} = 4$$

$$(4r_3) = x^3 + 3x^2 + 3x + 2$$

$$r_2 - 4r_3 = (x^3 + 4) - (x^3 + 3x^2 + 3x + 2) = 2x^2 + 2x + 2 = r_4$$

$$r_4 \cdot 3 = 2^{-1} = 3$$

$$3r_4 = x^2 + x + 1$$
